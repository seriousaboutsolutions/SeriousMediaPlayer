# Documentation for SeriousMediaPlayer

This directory contains the complete set of project documentation.  The files are
written in Markdown and can be viewed directly on GitHub or rendered by a static
site generator.

* **docs/overview.md** – High‑level description of the project.
* **docs/installation.md** – Step‑by‑step install instructions.
* **docs/usage.md** – Quick‑start guide and API reference.
* **docs/architecture.md** – Architecture diagram and component overview.
* **docs/contributing.md** – Contributor guidelines.
* **docs/license.md** – Full license text.
* **docs/changelog.md** – Human‑readable changelog.

Feel free to extend or edit any of these files as the project evolves.

# Overview

SeriousMediaPlayer is an extensible Python‑based media player designed for viewing and converting video evidence. It focuses on:

* **Reliability** – deterministic playback for forensic review.
* **Extensibility** – plug‑in architecture for custom decoders, filters, and exporters.
* **Conversion** – lossless transcoding pipelines that preserve metadata.

The player can be used as a command‑line tool or imported as a library in other Python projects.
